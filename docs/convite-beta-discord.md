# Beta do MATRIX Launcher 🪐

Quer ajudar a melhorar o **MATRIX Launcher**? Estamos procurando jogadores para testar a versão beta e relatar problemas.

**Como participar:** baixe pelo link oficial **[INSERIR LINK]** e execute `MATRIX Launcher Setup 0.3.1.exe` (Windows 10/11, 64 bits). Envie somente o instalador.

⚠️ Esta é uma versão de teste: podem ocorrer erros. O instalador não tem assinatura digital, então o Windows pode exibir um aviso. Baixe apenas pelo link oficial. A atualização automática ainda não foi validada; novas versões podem exigir instalação manual. Faça backup dos seus mundos antes de testar.

Encontrou um problema? Compartilhe neste canal o que tentou fazer, o que aconteceu e, se puder, uma captura de tela. **Não envie senhas ou tokens.** Obrigado por ajudar a MATRIX Community!
